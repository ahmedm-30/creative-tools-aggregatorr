About Creative Tools Aggregator

We are Mohammed Hakami and Ahmed Mahrous, students in CPIS-358: Internet Application and Web Programming. This website is our group project for Assignment 1, designed to help users discover and compare creative tools for design and coding.

Our goal was to create a simple, informative platform that showcases essential tools in a clear and organized way. We focused on usability and accessibility, making sure users can easily navigate between pages and understand each tools purpose.

The site includes structured tables for Design and Coding tools, internal links for smooth navigation, and image mapping that connects visuals to the About Us page.

In the future, we hope to expand this platform with user reviews, tool ratings, and search functionality to make it even more useful.

Our Mission

We aim to provide a clean and user-friendly environment where visitors can quickly access tool information, compare features, and make informed decisions.
